INVENTARIOS_IPSICOL - VERSION WEB

1. Abre GUIA.md: contiene los pasos completos en español.
2. Crea Supabase Free y ejecuta schema.sql y luego permisos.sql.
3. Genera la contraseña de acceso: python ipsicol.py --hash-password
4. Sube el proyecto a GitHub y despliega ipsicol.py en Streamlit Community Cloud.
5. Configura Secrets con el modelo secrets.example.toml y tus valores reales.

El archivo principal sigue llamándose ipsicol.py. En esta versión NO se utiliza
PyInstaller ni el archivo .exe. Los usuarios entrarán por un enlace web.

Incluye ingresos y salidas numerados, PDF con firmas opcionales, adjuntos
posteriores, consulta, devoluciones, corrección de productos y eliminación.
Las tablas se actualizan automáticamente cada 10 segundos.

La nube aún no está conectada: faltan tus credenciales y la publicación.
Los planes gratuitos tienen límites; consulta el apartado 7 de GUIA.md.
Los PDF de ejemplos contienen datos ficticios y son constancias internas.
